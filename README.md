# 真玥桌面连接器

此仓库仅用于安装包下载、使用说明和版本校验，不包含业务数据或私有源码。

测试版：Mac 1.0.3（macOS 14+，Intel/Apple Silicon）；Windows 1.0.2（Windows 10/11 x64）。

Mac 尚未公证，Windows 尚未签名或完成实机验收。请先在空白测试文档中验收。
